# 交付路线图

## 已完成

- 知识库操作：文档状态、上传、注入扫描、重试和索引移除。
- 业务数据基础：从带版本号的 CSV 文件导入的 SQLite 用户、设备和月度使用记录。
- RAG 质量保障：15 条标注用例、Recall@K 和 MRR 评测，以及 JSON 报告输出。
- 客服工作台：演示用户选择、浏览器授权定位、实时天气和可审阅的工具调用摘要。

## 下一步

- 添加数据导入任务、审计日志和内容所有者审核工作流。
- 用经过身份验证的账户替换演示用户，并集成工单/CRM系统。
- 在现有检索评测基础上，添加工具调用成功率、答案质量、反馈收集和生产环境监控功能。
- 为模型增加长期会话记忆、人工转接与客服反馈闭环。
