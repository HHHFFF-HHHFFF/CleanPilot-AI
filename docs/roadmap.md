# 交付路线图

## 已完成

- 知识库操作：文档状态、上传、注入扫描、重试和索引移除。
- 业务数据基础：从带版本号的 CSV 文件导入的 SQLite 用户、设备和月度使用记录。
- RAG 质量保障：15 条标注用例、Recall@K 和 MRR 评测，以及 JSON 报告输出。
- 客服工作台：演示用户选择、浏览器授权定位、实时天气和可审阅的工具调用摘要。
- 多 Agent 编排：调度 Agent、知识问答 Agent、故障诊断 Agent、用户运营 Agent，以及结构化路由、最小工具权限和用户数据强制绑定。
- API 身份闭环：FastAPI 登录、PBKDF2 密码哈希、短期 JWT、当前用户/设备接口，以及按令牌用户执行的 NDJSON 流式多 Agent 对话。
- React 用户端：登录、会话身份恢复、设备概览、自动定位天气、流式 Agent 处理摘要、Markdown 回答和响应式布局。
- 账户会话历史：SQLite 会话与消息表、按用户隔离的增删查 API、流式结果自动落库，以及桌面左栏和移动端历史抽屉。

## 下一步

- 增加 React 设备详情、历史报告和账户设置页面，并保留 Streamlit 作为内部知识库运营后台。
- 增加刷新令牌、登录限流、审计日志、账户管理，并集成真实工单/CRM 系统。

- 为模型增加长期会话记忆、人工转接与客服反馈闭环。
- 为故障诊断 Agent 增加多模态图片识别，并将稳定业务流程沉淀为可复用 Skill。
