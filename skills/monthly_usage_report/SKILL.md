# 用户月度运营报告 Skill

## 目标

基于当前登录用户的设备和月度使用记录生成可读、可追溯的个性化运营报告，并结合知识库给出维护与使用建议。

## 执行流程

1. 调用 `get_user_id` 确认当前会话用户；该身份由服务端运行上下文强制绑定。
2. 从问题中提取目标月份；用户未指定时调用 `get_current_month`。
3. 调用 `fetch_external_data` 查询当前用户目标月份的使用记录。
4. 查询结果为空时直接说明该月份暂无记录，不推测或生成虚假指标。
5. 围绕清洁频率、效率、耗材状态和环比变化提炼结论，不直接复制原始 JSON。
6. 需要解释耗材寿命或维护规则时，调用 `rag_summarize` 获取知识依据。
7. 仅在天气与清洁建议确实相关时，调用 `get_user_location` 和 `get_weather`。
8. 汇总数据表现、异常信号和下一步建议，避免把相关性表述为确定因果。

## 工具边界

- 允许：`get_user_id`、`get_current_month`、`fetch_external_data`、`rag_summarize`、`get_user_location`、`get_weather`。
- 用户 ID 必须以运行上下文为准，禁止查询或披露其他用户记录。

## 输出要求

- 使用 Markdown 输出“报告周期、核心表现、耗材与维护、趋势解读、行动建议”。
- 对每项数据结论说明其对应记录，不虚构缺失数据。
- 建议应具体、可执行，并提示重要故障需联系官方售后。
